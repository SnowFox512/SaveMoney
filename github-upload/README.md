# 我的攒钱计划

一个移动端优先的个人记账与储蓄计划网页。使用 React、TypeScript、Vite；数据只存于当前浏览器的 `localStorage`。

## 运行

需要 Node.js 20 或更新版本与 pnpm。

```bash
pnpm install
pnpm dev
```

打开终端提示的本地地址，通常是 `http://localhost:5173/`。

```bash
pnpm build
pnpm test
```

## 目录

- `src/types.ts`：账本、钱包、愿望和设置的数据类型。
- `src/logic.ts`：整数分金额、预算周期、每日合计、旧数据迁移、钱包余额、结转和储蓄预测。
- `src/App.tsx`：页面组织、钱包与记录状态、导入导出。
- `src/components.tsx`：初始化、记账、账单条目、愿望、统计和设置组件。
- `src/style.css`：移动端优先的视觉样式。
- `tests/logic.test.mjs`：日期、金额、结转、编辑删除和预测计算测试。

## 计算约定

- 金额在存储和计算时都是整数分；界面统一显示人民币元。
- 每月固定收入按设置的分配额自动记入三个钱包，作为计算得出的记录，不会重复写入本地存储。请不要再手动把同一笔固定收入记一次。
- 初始化余额代表建立计划当天的实际余额。如果当天已过发放日，本期预算由这些初始余额体现，下一周期起自动加入分配额。
- 改动预算设置会重新计算历史周期；建议在正式记账前确认基础预算。如果以后需要保留每次调整前的历史预算，可增加预算版本记录。
- 娱乐费和生活费结转只给出建议，点击“转入储蓄”才会生成转账。
- 支出按“日期＋生活费/娱乐费钱包”保存当天总额；再次保存同一天同一钱包会替换之前的金额，不会重复扣款。收入和钱包转账仍单独记录。
- 愿望清单中处于“想买”状态的所有大目标自动显示在首页，价格之和就是当前总目标。储蓄依清单顺序分配展示；修改、购买、放弃或删除愿望后自动重算。
- 打开旧版数据或导入旧版备份时，原有钱包余额、收入和转账保留，同一天同钱包的旧支出合并。固定的 MacBook/毕业旅行目标移除；旧版原始 JSON 会额外备份在浏览器存储的 `saving-planner-v1-legacy-backup`。
- 浏览器存储不会自动跨设备同步。换设备前请在设置中导出 JSON，再到新设备导入。
